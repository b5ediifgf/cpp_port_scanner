# Сканер TCP-портов на C++ 🚀

Легковесная и быстрая консольная утилита для сканирования TCP-портов, написанная на C++ с нуля с использованием системных сокетов. Проект разработан в Kali Linux для демонстрации основ сетевой разведки и аудита безопасности.

## ✨ Особенности
* **Высокая скорость:** Написан на чистом C++ для максимально быстрой работы.
* **Сетевые сокеты:** Создан без тяжелых сторонних библиотек, только стандартные системные вызовы.
* **Умный таймаут:** Ожидание ответа от порта ограничено 1 секундой, чтобы программа не зависала на закрытых портах.
* **Анализ популярных портов:** Настроен на проверку самых важных портов (21, 22, 23, 80, 443, 8080 и др.).

## 🛠️ Компиляция и запуск в Kali Linux

* Откройте терминал и введите `<sudo apt update && sudo apt install build-essential -y>`
* Затем `<g++ -O3 scanner.cpp -o port_scanner>`
* `<./port_scanner>`
